# 0G: how Odyssey uses it

0G Galileo is where Odyssey's money and judgement live: two contracts, 0G Storage for large payloads and episode logs, and a 0G Compute vision model that decides what gets stored. Diagrams and a demo path: [TRACKS.md, 0G](../TRACKS.md#0g-payments-contracts-and-storage).

## Prize: Physical AI, Agents with a Body

The glasses are the body; 0G decides at the capture checkpoint and keeps the record. Motion and capture stay on the device.

| 0G requires | How Odyssey meets it | Code |
|---|---|---|
| A 0G call inside the decision loop | Every image upload asks a vision model on 0G Compute for `capture`, `skip` or `stop`, and the gateway acts on that answer before anything is stored | [`ingest/route.ts:64`](https://github.com/AnaSyLabs/Odyssey/blob/4c4aa82961f61a6da434d7895f5f10e2f3605d89/web-monorepo/apps/web/app/api/ingest/route.ts#L64), [`gate-core.ts:42`](https://github.com/AnaSyLabs/Odyssey/blob/4c4aa82961f61a6da434d7895f5f10e2f3605d89/web-monorepo/apps/web/lib/gate-core.ts#L42) |
| An episode log on 0G Storage with a request id per decision | One JSON record per decision (device, content hash, action, reason, model, 0G request id, outcome), uploaded to 0G Storage | [`gate.ts:26`](https://github.com/AnaSyLabs/Odyssey/blob/4c4aa82961f61a6da434d7895f5f10e2f3605d89/web-monorepo/apps/web/lib/gate.ts#L26) |
| A replayable simulation or a live hardware demo | `npm run replay:gate -- path/to/images` replays a folder of images through the same loop and writes `episodes.jsonl`; the ESP32 glasses are the real hardware | [`replay-gate.ts`](https://github.com/AnaSyLabs/Odyssey/blob/4c4aa82961f61a6da434d7895f5f10e2f3605d89/web-monorepo/apps/web/scripts/replay-gate.ts) |
| A safe-stop that never fakes the decision | Timeout, 402, 429, 5xx or an unusable answer all become `GateUnavailable`; the API returns `503` and stores nothing. There is no local fallback decision | [`gate-core.ts:66`](https://github.com/AnaSyLabs/Odyssey/blob/4c4aa82961f61a6da434d7895f5f10e2f3605d89/web-monorepo/apps/web/lib/gate-core.ts#L66), [`ingest/route.ts:71`](https://github.com/AnaSyLabs/Odyssey/blob/4c4aa82961f61a6da434d7895f5f10e2f3605d89/web-monorepo/apps/web/app/api/ingest/route.ts#L71) |

## Status

Both contracts are deployed and tested, and the consensus contract was run by hand live. A full subscribe-and-claim round trip, a large 0G Storage payload and a live capture-gate call (it needs an `OG_COMPUTE_API_KEY`) have not been confirmed end to end. Contracts are unaudited testnet deploys.
